# Green Cardinal KE Platform

## Goal
Build a polished, youth-centered digital platform that presents Green Cardinal KE as a credible Kenyan movement for climate action, water security, conservation, education, leadership, and youth participation.

## Public experience
- Create a distinctive shared identity with a sticky responsive menu, image-led presentation, clear joining actions, accessible forms, and a consistent footer.
- Build separate pages for Home, About Us, Our Work, Programs, Opportunities, Impact, Resources, Get Involved, Partners, and Contact.
- Use the selected “Frosted Canopy” direction: forest green, water blue, warm highlights, editorial typography, strong youth-action photography, soft translucent surfaces, and restrained motion.
- Add project, opportunity, story, and resource search/filter experiences; bookmarks; image galleries; video embeds; charts; a Kenya project map; downloadable reports; and social sharing.
- Include membership, volunteer, mentor, partnership, contact, newsletter, and opportunity-submission forms.

## Content and imagery
- Use Green Cardinal KE throughout and write credible placeholder copy where organization-specific facts are still unavailable.
- Generate cohesive Kenyan youth climate-action imagery rather than shipping generic image placeholders.
- Clearly avoid inventing official contact details, team identities, partners, or impact claims; label demonstration figures and entries so they can be replaced.

## Administration and data
- Enable Lovable Cloud for secure sign-in, persistent content, submissions, subscriptions, bookmarks, and file management.
- Create role-based administration for projects, opportunities, articles, resources, statistics, team profiles, partners, applications, inquiries, and subscribers.
- Keep public content readable without sign-in while restricting management screens and records to authorized administrators.
- Seed editable demonstration content so every major page is useful on first launch.

## Quality checks
- Add unique search and social metadata to every public page.
- Verify keyboard accessibility, contrast, responsive layouts, loading/error/empty states, forms, filters, and key navigation on desktop and mobile.
- Confirm the site builds cleanly and the main public and administration journeys work.

## Technical details
- Use the existing TanStack Start application and its semantic Tailwind design tokens.
- Keep reusable public content, form fields, filters, and admin tables data-driven so Green Cardinal KE can later expand beyond Kenya without redesigning the interface.
- Use Lovable Cloud authentication, database, and storage with row-level access controls and a separate administrator-role table.
